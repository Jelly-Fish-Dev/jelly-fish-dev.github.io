Desktop application for viewing and editing audio file metadata across 13 formats including MP3, FLAC, OGG, and MP4, built using the [mutagen](https://mutagen.readthedocs.io/) library. Integrates with the [MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API) for automatic tag lookup and enrichment.

Published to the [Arch User Repository (AUR)](https://aur.archlinux.org/) and actively maintained.
